> **Desenvolvido por:** Guilherme Felberque & Equipe  

---

## 📌 Sobre o Projeto

Este repositório contém a primeira fase do projeto de réplica do site oficial da **Automobili Lamborghini**. O objetivo desta etapa consistiu na escolha de uma montadora e no desenvolvimento completo do Front-End da **Front Page (Home)**, além do **Menu Overlay** e da tela de **Dealer Locator (Localizador de Concessionários)**.

Conforme os requisitos da atividade, este projeto foi preparado para ser entregue à próxima equipe com toda a documentação necessária e um checklist detalhado das funcionalidades implementadas.
